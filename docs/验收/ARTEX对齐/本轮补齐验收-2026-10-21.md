## 4. 浏览器实际路径与证据

本地模型替身只接收 Chat Completions，不转发外网。目标是本轮本地真实 HTTP fixture。操作包含：

1. 通过页面创建自主探索任务，选择 `127.0.0.1:29191` 的自定义种子，并提交仅开放 get_endpoint/register_asset 的自定义 profile。
2. 通过页面启动 Run；暂停时释放已在途模型响应，确认没有新增目标请求；提交 Steer 后恢复，下一轮读取到人工指导。
3. Worker 真正 GET fixture，保存 Fact、Finding、host 关系及完整产物；Planner 提交真实证明并完成。页面可读产物、定位 proves 关系、用 evidence_id/reason 提交证明。
4. 页面人工 Hint 拒绝非法资产 UUID，接受本 Run 的合法资产，保留原目标。
5. 页面人工审核后，fixture 从 200/SECRET_MARKER 改为 403/SECRET_ACCESS_DENIED，启动独立 verifier。服务端判 fixed，原 Run 仍 completed，人工审核和历史行保留，相关 Goal 变为 open。
6. 第二个 Run 在 Worker 第一次请求处挂起；页面先暂停再停止，追加一次预算授权；显式开启 Epoch 2，Planner 继续原 WorkItem，产生新 Attempt 并完成。页面同时可见 Epoch 1 stopped 与 Epoch 2 completed。

```bash
cd backend
```

## 6. 已知边界与有意适配

- 提取式协议检查点不是 Norma SDK 的语义 compaction；数据库产物不是对任意 Shell/代理流量的自动录制。当前单产物有 8 MiB UTF-8 上限。
- profile 工厂是扩展边界，本轮用本地适配器证明；没有连接实际 MCP/skills 服务或通用命令执行环境。
- 规范 host/IP/service/app 从既有授权 endpoint 推导，无端口扫描或外部 DNS 推断；不会扩张执行范围。
- 来源 `verified` 不等于任意自然语言描述已被数学证明或漏洞已利用。旧报告可缺少结构化复测条件，此时不能自动生成 fixed/reproduced；人工审核历史独立保存。
- 暂停采用在线屏障，已发送请求不承诺撤回；停止后 Epoch 恢复的是对话与调度资格，不恢复外部工具进程，也不保证副作用恰好执行一次。
- 复合外键 NOT VALID 保护新写入，历史关联未逐条清洗。意图身份使用规范字段和来源版本，不提供任意自然语言的语义等价去重。
- 本地替身验证工程不变量，不能证明真实模型面对未知目标时的探索质量、漏洞发现率或长时成本。真实模型综合评估是下一阶段。
- 验收时工作区尚未形成 Git 提交；后续按用户要求单独提交，开发运行进程未重启；本地 AGENTS.md 不在上传范围。
